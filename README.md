### What I've shipped

- **10M+ downloads**: at **Comera Pay**, raised crash-free users from **93% to 98%** and ANR-free users from **90% to 99%**, and shipped Google Pay, Abu Dhabi government payments and UAE PASS digital-ID sign-in.
- **Secure login**: rebuilt secure token storage and exchange, ending forced logouts and payments stuck mid-flow.
- **1M+ downloads**: split **Abu Dhabi Islamic Bank's** legacy app into modules, cutting builds from **15–20 to 7–8 minutes** without pausing feature delivery.
- **Three teams, one feature**: drove secure second-device registration to production across mobile, identity and backend teams.
- **Hardened against attack**: owned app shielding with the security vendor (obfuscation, ProGuard/R8, root and Frida detection); every release passed penetration testing with no critical findings.
- **AI in the workflow**: built Claude skills my team adopted as internal tools; every AI change reviewed and tested.
- **Crypto R&D**: Kotlin and JNI/NDK bindings over C/C++ crypto libraries (secp256k1, BIP32, BIP39), and a Bitcoin wallet migrated from Java to Kotlin.
